Daggerheart Desert Campaign

This repository contains the documentation, worldbuilding, campaign reference material, and supporting assets for the Daggerheart Desert Campaign, a mythic desert-fantasy campaign built for Daggerheart and inspired heavily by Egyptian culture, religion, and mythology. It also serves as a foundation for related campaigns that may branch from the same setting.

For AI Agents

Before working with this repository, review AGENTS.md in the repository root. It contains the project-specific instructions for handling canon, sources, campaign continuity, Daggerheart mechanics, visual references, and new material.
